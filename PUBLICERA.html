Publicera klimatmodellen
med GitHub och Streamlit

Projektpaketet innehåller appen, beräkningsmotorn och modellunderlaget. Följ stegen nedan för att få en delbar webbadress.

Stella behövs inteIngen API-nyckelPython 3.12
1

Packa upp projektpaketet

Ladda ned Jagersro_Streamlit_v1.zip. I Windows: högerklicka på filen och välj Extrahera alla. Öppna den uppackade mappen klimatmodell_streamlit.

Här ska du bland annat se streamlit_app.py, requirements.txt och mappen model.

2

Lägg projektets innehåll i GitHub

Öppna github.com/new och logga in. Skapa exempelvis ett repository med namnet jagersro-klimatmodell.

Välj Add file → Upload files, eller länken för att ladda upp befintliga filer i ett tomt repository. Dra in alla filer och undermappar från projektmappens insida. Välj sedan Commit changes.

Viktigt: Ladda upp den uppackade mappens innehåll. GitHub och Streamlit behöver kunna se Python-filerna och mappen model; det räcker inte att lägga dit zip-filen.

Låt även mapparna .streamlit och .github följa med. Den förra styr utseendet och den senare innehåller automatiska kontroller.

3

Skapa appen i Streamlit

Öppna share.streamlit.io och logga in med ditt GitHub-konto. Välj Create app och alternativet att använda en befintlig app om den frågan visas.

FältVad du ska välja
RepositoryDitt repository, exempelvis dittnamn/jagersro-klimatmodell
Branchmain
Main file pathstreamlit_app.py
Advanced settings → Python3.12
SecretsLämnas tomt

Välj en ledig appadress om du vill, och klicka på Deploy.

Om filerna ligger i en undermapp i GitHub behöver startfilens sökväg också innehålla undermappen. Anvisningen ovan förutsätter att du laddat upp projektets innehåll direkt i repositoryts rot.

4

Kontrollera starten och dela länken

När appen öppnas ska grundscenariot heta Sparade reglage i Stella. Med slutår 2050 ska Saldo enligt Stella vara ungefär 307 192 ton CO₂e.

Öppna Modell & kontroll och välj att köra kontrollen på nytt. Den ska ge 681 av 681 godkända serier. Prova också att öppna varje flik och ändra ett antagande.

Dela appens adress på streamlit.app. Kontrollera delningsinställningarna så att den avsedda målgruppen kan öppna länken.

Den faktiska driftsättningen görs från ditt konto. Paketet har inte redan publicerats.

Så arbetar du med scenarier

Ändra antaganden: skriv i kolumnen Värde och välj Beräkna med dessa värden. Fler parametrar finns under Alla parametrar. Kurvor kan ändras under Tidskurvor.

Andelar: använd normalt 0–1. Skriv till exempel 0,25 för 25 procent. Av/På är 0 eller 1. De fem stomandelarna för respektive byggnadstyp ska tillsammans bli 1.

Spara arbetet: välj Spara scenario (JSON). Filen behåller antaganden och ändrade kurvor och kan läsas in igen. Exportera årsresultat eller utvalda tidsserier som CSV för svensk Excel.

Årsväljaren: ändrar vilket år som sammanfattas. Beräkningen kör alltid hela perioden 2024–2050.

Vad har verifierats?

Beräkningsmotorn har jämförts mot alla 681 sparade variabler och tidsserier, med 2 344 711 lagrade referensvärden i Stella-filen. Alla jämförelser klarar toleransen. Elva automatiska tester har godkänts.

Streamlit-starten återstår att verifiera: Streamlit kunde inte installeras i leveransmiljön. Ett starttest ingår och körs i GitHub Actions när projektet laddas upp. Kontrollera därför att GitHubs Actions-flik visar en godkänd kontroll och att appen visas som avsett.

Originalets klimatantaganden är bevarade. Dokumentationen beskriver identifierade problem i originalets formler och summeringar; de har inte rättats i denna konvertering.

Fördjupning finns i README.md och docs/METOD_OCH_KONTROLL.md i projektpaketet.

Om appen inte startar

ModuleNotFoundError: kontrollera att alla Python-filer och requirements.txt finns med. FileNotFoundError: kontrollera mappen model och dess filer. Fel vid installation: kontrollera att Python 3.12 valts.

Öppna loggen i Streamlit via Manage app och spara den första feltexten om felet kvarstår. I GitHub visar fliken Actions resultatet av de automatiska testerna.
